# StudyMate

## About
StudyMate is a personalized, inclusive study app for students of all learning styles. It provides tools like flashcards, editable notes, and practice tests, with accessibility features for a better learning experience. Ideal for students who want to organize, review, and track their study progress efficiently.

## Key Features

- **Flashcards**
  - Create keyword-definition pairs
  - Organize by topic and track completion
  - Edit or delete cards anytime

- **Study Notes**
  - Upload documents and convert them into editable notes
  - Supports text-to-speech and font size adjustments

- **Practice Tests**
  - Generate multiple-choice quizzes based on your notes

- **Calendar**
  - Add and manage tasks by date
  - Track deadlines with automated countdowns

- **User Dashboard**
  - Personalized greeting and study summary
  - Quick links to core tools

- **Accessibility**
  - Text-to-speech for all study content
  - Colorblind-friendly UI option
  - Adjustable font size and dark mode

## Tech Stack

* **Flutter** - UI Framework
* Dart** - Programming Language
* **Firebase** - Backend / BaaS

## Getting Started

1. Clone or download this repository
2. Navigate to the project directory
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Usage Notes

- **Onboarding**: Introductory flow with feature highlights
- **Signup/Login**: Secure user authentication
- **Topic Selection**: Choose your subject areas of interest
- **Home**: Study progress overview with shortcuts to features
- **Flashcards/Notes/Tests**: Dedicated tools for active study
- **Accessibility Settings**: Customize the app to suit user needs
- **Calendar**: Track tasks and deadlines visually
- **Profile**: Edit name, email, photo, and banner image
